# The Studio Airbnb — Website

Production-ready static website for GitHub Pages.

## Publish
Upload all files and the `assets` directory to the repository root. Enable GitHub Pages from `main` / `(root)`. No build step is needed.

## Site management
- Booking enquiries and guest feedback open WhatsApp for guests to send their messages.
- Airbnb booking button opens the official listing.
- The location page includes a map and the supplied Google Maps pin link.
- Feedback is not stored or published automatically; add approved testimonials manually if desired.
- To update photos, replace the relevant images in `assets` while retaining filenames.

The Experience page describes verified property features and links to the official Airbnb listing for guest reviews. No guest testimonials are fabricated.

Experience page includes five animated property experience highlights, not fabricated guest reviews. Replace with verified guest testimonials when available.

Guest testimonial cards are clearly marked as illustrative previews. Replace them with genuine permissioned reviews before representing them as customer testimonials.


## Guest review cards
The five first names and quotes in the scrolling cards are illustrative placeholders, NOT real guest testimonials. Replace them with verified guest feedback and names before describing them as authentic reviews. The website labels them as sample reviews.
